# Full-Stack Project Management Platform

Modern project management application with Angular frontend, React dashboard, and Spring Boot backend.

## Tech Stack
- **Frontend:** Angular 17, React 18, TypeScript
- **Backend:** Spring Boot 3.2, Java 17
- **Database:** PostgreSQL
- **Real-time:** WebSocket (STOMP)
- **AI:** OpenAI for sprint planning and task estimation

## Features
- Kanban boards with drag-and-drop
- AI-powered sprint planning and estimation
- Real-time collaboration via WebSocket
- Role-based access control
- Angular main app + React analytics dashboard
- RESTful API with OpenAPI documentation
